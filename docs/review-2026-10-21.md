# VXLAN 关联审查优化（2026-10-21）

本轮从 `9226737` 开始，检查 Config/RuntimeParser、Collector、配置来源与关联、SubnetIndex、ACL 策略、Fabric 比较及计划输出边界。厂商命令解析器的名称和目录保持原契约；新增根目录 AGENTS.md，明确业务范围、会话所有权、证据和验证要求。

落实的性能改动位于 `Fabric::Review#review_address_groups`。旧实现为每个地址组重新遍历设备，再在每台设备的引用数组中执行 include?；每台设备引用 G 个不同对象时会产生平方级成员查找。现在逐设备去重引用并直接把证据归入对象索引，最后按对象名排序。设备证据顺序、重复引用去重、缺失定义的 nil 及只比较实际引用设备的行为保持不变。索引只活在本次审查中，不缓存过期配置。

`benchmark/fabric.rb` 使用两台设备、同名 ACL 引用不同成员定义的地址组，执行完整 Fabric 审查，并在计时外核对每个对象的差异、设备顺序、ACL 差异及没有生成变更。输入构造、网络和文件 IO 不计时。macOS arm64 / Ruby 4.0.6，独立基线库与候选库各运行两次，每次三个样本取中位数；区间为两个进程结果范围。
