# Fabric 业务一致性与交互下发实施计划

> 使用 executing-plans 在当前工作区逐项执行；保留既有 WIP，不提交、不发布、不实际下发。

**目标：** 同 Fabric 内已承载相同 VLAN/VNI 的 Leaf 提供一致网关和访问控制；保留部署范围差异。

**架构：** 显式 Fabric 成员策略限定比较域；Fabric::Review 比较完整配置的业务视图，ChangePlan 只渲染有限增量动作。报告默认只诊断，--scripts 显式输出候选与计划；apply 单计划单设备，真实终端明确确认后，读取当前配置、比对指纹、记录持久意图、顺序执行并回读验收。

**约束：** Ruby 4、独立 vxlan/wireless 项目；不根据多数无 ACL 删除访问控制；网关跨 VNI 地址冲突必须阻断；不跨 Fabric 借用模板；不复制身份参数；不自动保存或重放远端写入。

- [x] Fabric::Review：显式成员；同 VNI 网关/VRF/Anycast/MTU、ACL 挂载及有序内容、同网段跨 VNI 冲突；未部署业务单列覆盖，不列缺失故障。测试不同部署范围、ACL 缺失/同名异内容、少数 ACL 保留、网关迁移冲突、部分证据。
- [x] ChangePlan：可核验的设备身份、来源哈希、配置指纹、类型化动作、前提、回退与验收。先支持补挂/补建 ACL 与无冲突缺失网关；不自动覆盖冲突规则。
- [x] 报告/CLI：collect/review 默认诊断，--scripts 可选导出，--fabric-policy 显式比较域；旧报告离线重评，SZX8/SZX9 产出可审阅策略及报告。
- [x] apply：无 --yes；非终端拒绝；确认文字绑定主机和计划摘要；确认后再连设备；源配置变化、部分回显拒绝写入；每条命令前后落盘，失败/中断标记 uncertain、停止，不重放/自动回退；完整回读核对目标状态。验证取消、过期配置、命令失败、持久化失败和成功路径。
- [x] Wireless 同步可选脚本导出与交互 apply；模板原有加固建议保留停用/恢复前提，不把 Radio Down 自动变成开启指令。
- [x] 真实保存报告回放、完整测试与静态检查、打包验证，报告支持范围与未执行事项。

审查重点：不同 VLAN 相同子网的迁移、ACL 隐式 deny/顺序、引用存在但定义缺失、确认后被更改的计划、部分下发与报告落盘失败。
