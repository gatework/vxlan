## Ruby 与工程取舍

- 继续使用 Data 与 Immutable 表达不可变证据；解析过程中的可变状态保留在 ConfigurationState，避免给临时构建对象强加值对象语义。
- 设备字段和身份预检集中在 Options，Collect 负责流程编排；SSH 默认值统一声明，减少初始化与运行路径的规则漂移。
- 报告汇总用 Hash 索引已完成地址，pending 计算由逐项线性扫描改为 O(完成数 + 请求数)，保持原顺序和输出结构。
- 保留公开入口、记录字段与配置邻居键的原始拼写。已有 IPv4/IPv6 主机及动态前缀支持继续保留；未建模接口邻居语法保持部分证据。
- 保留独立 gem 的边界；跨厂商值转换继续复用 ctx_parser，传输回执复用 ctx_driver。线程取消回收、原子报告和目录同步保留现有所有权语义。
- 方法注释说明用途与证据边界，补充报告错误的发布阶段/提交状态说明。
